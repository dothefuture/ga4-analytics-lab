# Проверка перед сдачей

- [ ] Заполнены ФИО, группа, Property, часовой пояс, права и период.
- [ ] Все результаты относятся к указанным Property и периоду.
- [ ] `generate_lead` проверен как Key event; дата отметки учтена.
- [ ] В сравнении Instagram/Direct нет фильтра, исключающего Direct.
- [ ] Основной Funnel содержит 4 шага, Closed, Indirectly, без Within.
- [ ] Event count, пользователи Funnel и сеансы подписаны отдельно.
- [ ] Path содержит выбранные метрику и Node type.
- [ ] Основной кейс ограничен source И campaign на каждой вкладке.
- [ ] Общий фильтр Event name не обрезает Funnel/Path.
- [ ] Sheets сверены по уникальным непустым `request_id` отдельно от GA4.
- [ ] Ограничения данных и доступа описаны без придуманных чисел.
- [ ] Экспорты и восемь PNG открываются из репозитория.
