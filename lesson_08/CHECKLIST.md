# Проверка перед сдачей

- [x] Заполнены ФИО, группа, Property, часовой пояс, права и период.
- [x] Все результаты относятся к указанным Property и периоду.
- [x] `generate_lead` проверен как Key event; дата отметки учтена.
- [x] В сравнении Instagram/Direct нет фильтра, исключающего Direct.
- [x] Основной Funnel содержит 4 шага, Closed, Indirectly, без Within.
- [x] Event count, пользователи Funnel и сеансы подписаны отдельно.
- [x] Path содержит выбранные метрику и Node type.
- [ ] Основной кейс ограничен source И campaign на каждой вкладке.
  (Funnel ограничен; Path по всем пользователям — фильтр по параметрам
  сеанса в Path недоступен.)
- [x] Общий фильтр Event name не обрезает Funnel/Path.
- [x] Sheets сверены по уникальным непустым `request_id` отдельно от GA4.
- [x] Ограничения данных и доступа описаны без придуманных чисел.
- [ ] Экспорты и восемь PNG открываются из репозитория.
  (PNG на месте, экспорты GA4 не выгружались.)
