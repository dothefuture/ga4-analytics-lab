# Проверка перед сдачей

- [ ] В GA4-выгрузке удалены служебные строки и «Общий итог».
- [ ] Листы названы `ga4_traffic`, `ga4_leads`, `leads`.
- [ ] `generate_lead` выгружен отдельно; трафик событием не отфильтрован.
- [ ] В подключении три листа, заголовки листов GA4 включены.
- [ ] Числа целые с агрегацией «Сумма», дата GA4 — `DATE_PARSE`.
- [ ] `source` и `campaign` приведены к `direct`, `not_set`.
- [ ] `name` и `email` скрыты.
- [ ] `Lead Count` и `Done Count` используют `COUNTD(request_id)`.
- [ ] В сводной таблице связи только по `source`, `campaign`, `Дата`.
- [ ] `null` не заменён нулём; несовпавшие пары разобраны в сверке.
- [ ] Проверены алиасы и связи селекторов.
- [ ] Пользователи по дням не выданы за уникальных за период.
- [ ] Публичный доступ выключен.
- [ ] Бланк, сверка и пять PNG заполнены фактическими данными.
